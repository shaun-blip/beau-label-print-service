# Designer changes, 16 November 2026, fifth round: wedding, engagement and bridal designs

Twenty-seven new designs built from Shaun's clipart. Apply after the Thanksgiving and birthday rounds (c and d): this file's script uses helpers defined in those two scripts.

## What's new

**Eleven picture designs** where the customer's words are the headline. They lead the list for every wedding occasion; Greenery Wreath is the new default there.
`wd-wreath` Greenery Wreath, `wd-ring` Watercolor Ring (Engagement and the bridal occasions only), `wd-frame` Botanical Frame, `wd-circle` Botanical Circle, `wd-bands` Wedding Bands, `wd-roses` Rose Sketch, `wd-cake1` Tiered Cake, `wd-cake2` Floral Cake, `wd-cake3` Rose Cake, `wd-tower` Champagne Tower, `wd-doodles` Wedding Doodles.
All the line drawings print in the customer's chosen color, so they work with every palette, dark backgrounds included.

**Two number designs.** Both read the number from what the customer typed (first number in the main line, then the top line, then the detail line; a milestone birthday falls back to the age).
- `wd-tablescript` Script Table Number (Table bottles only): draws "table no." and the number as a calligraphy word, one to thirty. Typing "Head table" in the main line draws that instead. With "Different on each label", one sheet can carry tables one to eight.
- `wd-number` Watercolor Number (Anniversary, Table bottles and every birthday occasion): draws the number in large watercolor numerals.
On both, the main line is used by the artwork instead of being printed as text (`uses:["main"]`), so the field stays editable.

**Fourteen lettering designs** (headline is artwork; all but two print in the chosen color):
`wd-saidyes`, `wd-engaged` (fixed colors), `wd-savedate1`, `wd-savedate2`, `wd-weddingday1`, `wd-weddingday2`, `wd-happywedding`, `wd-happywed`, `wd-mrmrs`, `wd-justmarried`, `wd-celebratelove`, `wd-lovestory`, `wd-loveday` (also Valentine's Day and Galentine's), `wd-anniv`.

Not used from this batch: the floral letter "O" (one letter only), the chalkboard table card, the botanical arch and the "bouquet" header frame.
