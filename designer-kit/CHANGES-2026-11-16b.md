# Designer changes, 16 November 2026, second round

Apply after CHANGES-2026-11-16.md. Two changes to the wrap step. Drawing code is untouched; no print service redeploy.

## What changed

1. **Bundle note is back.** The "Build a bundle, unlock free wraps" box returns under the wraps, with the same tiers ($39 for 2 free wraps, $79 for 5, $119 for 10). It now tells the customer they choose their free wraps in the cart, because the cart is where the store offers them. The page does not add free wraps itself.
2. **Wraps swipe sideways.** The wrap cards sit in one row that scrolls horizontally (touch swipe, trackpad, or the round arrow buttons), so the row can hold every wrap in the matched collection instead of stopping at a fixed number. Three cards show at a time on desktop, a little over two on phones so the next card peeks in. A line under the row says how many there are. Adding a wrap redraws the row without jumping back to the start.

## How to apply to the theme

Files touched in this kit: `designer.html`, `designer.css`, `js/06-app.js`, `js/07-print-and-events.js`. `tools/changes-2026-11-16b.json` holds the 8 exact `find` / `replace` pairs against the kit as it stood after the first round.

The theme's wrap step has already been rebuilt for real products, so some `find` strings in `buildWraps()` will not match. Carry the intent over by hand:

- Remove the "show more" button and its cap. Render every product that passes the size and stock filter into `#wrapcards`, best sellers first. Give card images `loading="lazy"` and a fixed height so the row doesn't jump.
- Take the CSS for `.wraprow`, `.wrapgrid`, `.wrapcard`, `.wrapnav` and the `.steps>section` line from `designer.css` as is. The `.steps>section` line matters: without it the row widens the page instead of scrolling.
- Take `syncWrapNav()` and its four event bindings as is. Call `syncWrapNav()` after every redraw of the row, and keep the row's `scrollLeft` across redraws as the kit's `buildWraps()` does.
- Put the bundle box back under `#wrapsum` and compute `cost` from the real prices of the chosen wraps.
